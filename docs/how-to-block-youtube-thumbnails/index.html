How to Hide YouTube Thumbnails (2026 Guide)

Thumbnails are the bait. Strip them out and YouTube becomes a list of titles you can actually read — far less tempting, far easier to leave. Here's the manual CSS route and the extensions that do it properly.

Updated June 2026 · Written by the CleanFeed team.

Thumbnails are the single most engineered part of YouTube. A title is just words, but a thumbnail is a designed object: the shocked face, the red arrow, the circled detail, the "you won't believe" composition. Creators A/B-test them obsessively because the thumbnail is what converts a passing glance into a click. That's exactly why hiding them is one of the most underrated ways to make YouTube less compulsive — and almost nobody talks about it, because there is no native setting for it.

This guide covers every working method in 2026. We'll start with the honest truth — YouTube gives you no toggle for this — then walk through a manual userstyle approach using Stylus and CSS (with a snippet you can paste in), and finally the browser extensions that hide thumbnails properly across the whole site. I built one of those extensions, so I'll flag my bias and tell you plainly where the free options are the smarter pick.

Why hiding thumbnails actually reduces impulse clicks

Impulse clicks are visual, not verbal. When you scan a feed of thumbnails, you're not reading — you're reacting to faces, colors, and motion-implied drama before the conscious, deliberate part of your brain catches up. The click happens in the gap between seeing and thinking. A bright, high-contrast thumbnail of a surprised expression is a tiny dopamine slot machine, and the whole homepage is a wall of them.

Strip the thumbnails away and that wall becomes a plain list of text titles. Suddenly you have to read "Pro Photographer Reacts To Cheap Cameras" instead of being grabbed by a zoomed-in shocked face and a red circle. Reading is slower and more effortful than reacting, and that small added friction is enough to break the autopilot. You start asking "do I actually want to watch this?" instead of clicking first and regretting it ninety seconds later. Clickbait only works when you can see the clickbait. Text titles are far less tempting precisely because they engage judgment instead of reflex — and titles tend to be more honest than thumbnails, nudging you toward substance over packaging.

The honest starting point: YouTube has no built-in "hide thumbnails" setting anywhere — not on desktop, not in the mobile app, not in account settings. Every method below is a workaround. There's no official toggle to flip, so you'll either write a bit of CSS yourself or lean on an extension that does it for you.

Method A: The manual route — a Stylus userstyle (CSS)

If you don't want to install a dedicated YouTube extension, you can hide thumbnails yourself with a userstyle manager. The most popular is Stylus, a free, open-source extension for Chrome and Firefox that lets you inject your own CSS into specific sites. The idea is simple: you write a rule that finds YouTube's thumbnail image elements and hides them, leaving titles and channel names intact. Here's how, step by step.

  1. Install Stylus

    Add Stylus from the Chrome Web Store (or Firefox Add-ons). It's a userstyle manager — it does nothing on its own until you write or import a style. It's lightweight and widely trusted, and unlike a full YouTube extension it only does what your CSS tells it to.

  2. Create a new style scoped to YouTube

    Click the Stylus icon, choose "Manage," then "Write new style." Give it a name like "Hide YouTube Thumbnails." In the "Applies to" section, set it to apply to the URL youtube.com so your CSS only runs on YouTube and nowhere else.

  3. Paste a thumbnail-hiding rule

    Drop in a starting snippet like the one below. It targets the image containers used in feed items and either hides them or collapses them to a thin neutral bar so the layout doesn't collapse awkwardly:

    /* Hide YouTube thumbnails — leave titles & channel text */
ytd-thumbnail,
ytd-playlist-thumbnail,
yt-thumbnail-view-model,
#thumbnail img,
a#thumbnail {
  visibility: hidden !important;
}

/* Collapse the empty thumbnail box so titles line up */
ytd-thumbnail,
yt-thumbnail-view-model {
  background: #1a2230 !important;
  min-height: 0 !important;
}

/* Optional: grey them instead of hiding outright */
/* #thumbnail img { filter: grayscale(1) brightness(.4) !important; } */

    Save with the keyboard shortcut or the "Save" button, then reload YouTube. The thumbnails should disappear or grey out while titles remain readable. Uncomment the last rule if you'd rather grey thumbnails (a softer approach that still kills the color-and-contrast pull) than remove them entirely.

  4. Tune it for the pages you use

    You'll quickly notice the rule doesn't catch everything. Search results, the watch-page sidebar, channel pages, and Shorts shelves each use slightly different markup, so you'll need to add more selectors as you spot thumbnails that slip through. This is the fiddly part: it's trial and error with your browser's element inspector.

Be honest with yourself about the trade-offs here, because they're real. The manual route is genuinely fiddly. YouTube renames its CSS classes and restructures its custom elements regularly, and every time it does, your selectors break and thumbnails reappear until you patch the style. You have no friendly toggle — to turn it off you disable the whole userstyle. It won't follow you to the mobile app (Stylus runs only in desktop browsers). And it's a blunt instrument: getting it to hide feed thumbnails without also breaking video player controls or your subscription avatars takes patience. For a tinkerer who enjoys this, it's free and infinitely customizable. For everyone else, it's maintenance you'll resent within a month.

The catch — and this is important — is that thumbnail hiding is a genuinely niche feature. Frequently asked questions

Can I hide YouTube thumbnails without an extension?

Only with a userstyle manager like Stylus, which still requires installing Stylus and writing CSS. YouTube itself has no native thumbnail setting on desktop or mobile. So the truly "no install at all" answer is no — but the Stylus route avoids a dedicated YouTube extension if that's your preference.

Why do thumbnails keep coming back after I hide them with CSS?

Because YouTube periodically renames its CSS classes and restructures its custom elements. A selector that matched a thumbnail container last month may match nothing today, so your userstyle silently stops working until you update it. Maintained extensions avoid this by shipping selector updates to you; a hand-written userstyle is yours to keep patching.

Will hiding thumbnails break video playback or the player?

It shouldn't, if your selectors are scoped to feed and list thumbnails rather than the player. A too-broad rule can accidentally hide player controls or channel avatars, which is exactly why the manual route takes tuning. Dedicated extensions are scoped carefully so the watch page and playback keep working normally.

Is greying out thumbnails better than removing them?

For many people, yes. Greyscale-and-dim keeps the page layout intact and still removes the color-and-contrast pull that drives impulse clicks, while leaving a faint visual anchor. Fully removing thumbnails is more drastic and turns the feed into a pure text list. Try both — CleanFeed lets you grey or hide, and the CSS snippet above includes a greyscale variant you can uncomment.

Does hiding thumbnails work on the YouTube mobile app?

No. Browser extensions and Stylus userstyles run only in desktop browsers, and the official mobile app doesn't support them. On a phone your best options are using a browser that supports extensions to visit the YouTube website, or relying on broader habits like browsing the Subscriptions tab. There's no thumbnail toggle inside the native app.

Is it safe to install Stylus or these extensions?

Stylus is open source and widely used, and it only does what your CSS instructs. Among the blockers, Unhook and CleanFeed are open source so you can read exactly what they do, and CleanFeed runs entirely on your device with no account, no telemetry, and no data leaving your browser. As always, install from the official Chrome Web Store and review the permissions before adding anything.
