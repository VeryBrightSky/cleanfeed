Focus Lock for deep work

Set a 4-digit PIN, lock every blocker on for 30 min – 2 h, or until you choose. PIN is salted-SHA256 hashed, never plaintext. Need out early? Hold to unlock for 60 seconds — the friction keeps impulsive unlocks at bay.

⏱

Daily time tracker

See how many minutes you actually spent on YouTube today and this week. Counted only when a tab is focused and visible — never background. Free for everyone.

🔑

Keyword blocking

Add words to a list — any video whose title contains them disappears everywhere on YouTube. Homepage, search, sidebar, subscriptions. Pro feature.

🍅

Pomodoro Focus Lock

Set 25-minute focus cycles. During focus, all blockers lock automatically. Break phase unlocks everything. Repeat for as many cycles as you want. Pro feature.

📄

Per-page rules

Different blocker settings for different YouTube pages. Hide the homepage feed on the homepage but show it on watch pages. On / Off / Inherit per blocker per page. Pro feature.
