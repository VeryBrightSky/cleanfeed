What now?

Manual fix (free): Make youtube.com/feed/subscriptions your homepage. Bookmark it. Never visit the youtube.com root again.

Soft fix (free): Install Unhook. It hides Shorts and the homepage feed. You can disable it any time — which is the catch.

Hard fix ($4.99 once): That's what I built CleanFeed for. Focus Lock with a PIN you can't talk yourself out of. Pomodoro. A time tracker that doesn't lie. One-time payment, because subscribing to focus felt like the wrong incentive.
