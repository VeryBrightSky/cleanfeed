# v1.4.1 — manual test checklist for Vito

Load `dist/cleanfeed-v1.4.1.zip` (or the unzipped `cleanfeed/` folder) into
`chrome://extensions → Developer mode → Load unpacked`. Then run through
each ☐ below. Each block has explicit steps + the expected outcome.

If anything ⚠ fails, note the section number and let me know.

---

## 1. Fresh-install onboarding (F2)

- ☐ Remove CleanFeed if present, then `Load unpacked`.
- ☐ The extension card should show **version 1.4.1**.
- ☐ Click the toolbar icon. The popup should show **3 onboarding cards**, not the toggle grid. The middle card "Focused" must have a teal **MOST POPULAR** tag.
- ☐ Click **Focused**. Expected: a Free user (default `paid: false`) sees only 2 free-tier blockers turned on, then the upsell modal opens automatically because the preset wanted more than free allows.
- ☐ Close the popup, reopen it. Onboarding should NOT reappear. The toggle grid should render with the 2 enabled blockers.

## 2. Migration from v1.3.x (F2 + F5)

- ☐ Open the popup → right-click → **Inspect** → in the popup's console run:
  ```js
  chrome.storage.local.set({
    settings: { "home-feed": true, "shorts": true, "comments": false },
    paid: false,
  }, () => location.reload());
  ```
- ☐ Popup should NOT show onboarding (migration auto-set `onboardingComplete=true`).
- ☐ Toggle grid should have **14 blockers** total. The four new ones (Playables, Merch shelf, Breaking news, Mixes & playlists) are all **OFF**.
- ☐ Previously-set toggles (`home-feed`, `shorts`) remain **ON**.

## 3. Keyword blocking (F1, Pro)

- ☐ Simulate Pro: in the popup console run
  ```js
  chrome.storage.local.set({ paid: true }, () => location.reload());
  ```
- ☐ Right-click extension icon → **Options** → scroll to **Hidden keywords** section.
- ☐ Type in:
  ```
  reaction
  clickbait
  drama
  ```
  Click **Save keywords**. Status line shows "Saved 3 keywords."
- ☐ Navigate to <https://youtube.com/>. Any home-feed card whose title contains "reaction", "clickbait", or "drama" should disappear within ~200 ms.
- ☐ Type "react" into YouTube search. Results page should also hide matching cards.
- ☐ Clear the textarea, click Save. All hidden cards should reappear (set the keyword count back to 0 — engine becomes a no-op).

## 4. Pomodoro mode (F4, Pro)

- ☐ Options page → **Focus Lock** section → set a PIN (e.g., `1234`). Confirm. Status updates to "PIN is set."
- ☐ Scroll to **Pomodoro Focus Lock**. Inputs: focus `2`, break `1`, cycles `2`.
- ☐ Type `1234` in "Enter PIN to start" → click **Start Pomodoro**. The PIN field clears; status reads `Session active — FOCUS phase, cycle 1 of 2`.
- ☐ Click the toolbar icon. Popup banner shows red `FOCUS m:ss · Cycle 1 of 2` ticking every second.
- ☐ Visit youtube.com. **All 14 blockers should now be force-active** regardless of toggle state.
- ☐ Wait ~2 minutes. A system notification fires: **Focus complete — break time**.
- ☐ Open the popup. Banner now shows `BREAK m:ss · Cycle 1 of 2`. Blockers are OFF (you can see the homepage feed).
- ☐ Wait ~1 minute. Notification fires **Break over — back to focus**. Banner returns to `FOCUS · Cycle 2 of 2`.
- ☐ After the final break, lock disengages. Popup hides the banner; toggles return to their saved state.
- ☐ In console: `chrome.storage.local.get(['lastPomodoroComplete'], r=>console.log(r))` — should show a Unix timestamp from the last few seconds.

## 7. Per-page rules (F6 — completed in v1.4.1)

- ☐ Options page → **Per-page rules** section → check **Enable per-page rules**.
- ☐ Open the popup. The toggle grid is now wrapped in a 4-tab bar: **Everywhere · Homepage · Watch page · Subscriptions**.
- ☐ "Everywhere" tab: behaves exactly like the v1.4.0 grid (normal on/off toggles).
- ☐ Click "Homepage" tab. Each blocker row now shows a 3-button segment: **On / Off / Inherit**. The active value is highlighted teal.
- ☐ On the Homepage tab, set `home-feed` → **Off**. On the Watch tab, set `home-feed` → **Inherit**.
- ☐ Visit youtube.com/. Homepage feed should be VISIBLE (homepage override forces it off).
- ☐ Click any video → /watch. Sidebar / etc. apply the Everywhere defaults (because Watch said inherit).
- ☐ In Homepage tab, change `home-feed` to **Inherit** → feed visibility now follows the Everywhere setting again.
- ☐ Uncheck **Enable per-page rules** in options. Popup reverts to the v1.4.0 single-grid layout. Behaviour identical to before opt-in.
- ☐ Edge case: Set `paid: false` in console while `perPageEnabled: true`. Popup should show ONLY the Everywhere tab and a small **Per-page rules is a Pro feature — Upgrade** banner.
