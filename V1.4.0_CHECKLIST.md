## Migration coverage

`background.js` adds `_migrateForV140()` invoked on `onInstalled` `reason === "update"`:

- New blocker keys (`playables`, `merch-shelf`, `breaking-news`, `mixes-playlists`) merged into `settings` with `false` defaults — existing toggles preserved
- `onboardingComplete` auto-set to `true` for any upgraded user whose settings already have at least one truthy entry (so existing users **don't** see the onboarding screen)
- `hiddenKeywords`, `usageCount`, `reviewPromptShown`, `perPageEnabled`, `perPageSettings` all initialised with safe defaults if missing
- `focusLock.mode`, `focusLock.pomodoro`, `focusLock.pomodoroState` added without disturbing existing PIN hash / activeUntil
